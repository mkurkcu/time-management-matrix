# Time Management Matrix

A desktop Eisenhower Matrix application built in Python with Tkinter.

## Features

- Add, edit, complete, and delete activities
- Score urgency and importance from 1–10
- Automatically assign tasks to Q1–Q4
- Interactive matrix with clickable task points
- Search and filter completed activities
- Optional due dates and notes
- Persistent local JSON storage
- JSON backup and CSV export
- Uses only the Python standard library

## Run

```bash
python app.py
```

Python 3.10+ is recommended. Tkinter is included with most standard Python desktop installations.

## Data

The app stores data locally at:

```text
~/EisenhowerMatrix/tasks.json
```

No personal task data is included in this repository.
